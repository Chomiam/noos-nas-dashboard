Comment connecter un nouvel appareil (PC, Smartphone, Tablette) ?
WireGuard est disponible gratuitement sur Windows, macOS, Linux, Android et iOS
1. Installez l'application WireGuard
Téléchargez l'application officielle WireGuard sur votre téléphone (App Store / Google Play) ou sur votre ordinateur (wireguard.com).
2. Configurez le pair dans NixOS
Ajoutez la clé publique de votre client dans la configuration NixOS du NAS pour lui attribuer une IP fixe dans le sous-réseau 10.100.0.x/32.
3. Connectez-vous en un clic
Activez le tunnel : vous avez désormais un accès direct et chiffré à vos partages Samba, votre serveur sFTP et au tableau de bord Noos sans ouvrir de ports vulnérables.
💡
Pourquoi utiliser WireGuard sur votre Noos NAS ?
Sécurisez l'accès à vos données sans exposer vos ports sur Internet
En activant WireGuard, vous accédez à vos partages Samba, vos sauvegardes sFTP et à votre tableau de bord Noos depuis n'importe où dans le monde (PC portable, smartphone) avec un chiffrement moderne haute performance, tout en conservant l'isolation stricte de votre réseau local.

Configuration dans FileZilla

          
    
            
  1. Ouvrez Fichier > Gestionnaire de sites (Ctrl + S) et cliquez sur Nouveau site.
    2. 
            
  2. Sélectionnez le protocole : SFTP - SSH File Transfer Protocol.
    3. 
            
  3. 
              Hôte : IP_LOCALE | Port : 22
            
    4. 
            
  4. Type d'authentification : Normal (avec identifiant et mot de passe de votre compte) ou Fichier de clé si vous utilisez une clé SSH privée.
    5. 
            
  5. Cliquez sur Connexion. Acceptez la première empreinte de clé d'hôte du NAS.
    6. 
          

        


        
        

          
Configuration Cyberduck & WinSCP

          
    
            
  1. WinSCP : Choisissez SFTP dans le menu déroulant du protocole, entrez l'adresse IP du NAS et votre compte. WinSCP gère la reprise automatique des téléchargements interrompus.
    2. 
            
  2. Cyberduck (macOS / Windows) : Cliquez sur Ouvrir une connexion, choisissez SFTP (SSH File Transfer Protocol), serveur IP_LOCALE, port 22.
    3. 
            
  3. Cochez Ajouter au trousseau pour enregistrer les identifiants de manière sécurisée.
    4. 
          

        


        
        

          
Ligne de Commande & Montage Réseau Virtuel (sshfs)

          
    
            
  1. 
              Client interactif sftp :
              
    
                sftp -P 22 utilisateur@nas
                
              
    
            
    2. 
            
  2. 
              Montage direct du dossier NAS sur votre ordinateur (Linux/Mac) :
              
    
                sshfs -p 22 utilisateur@nas:/ /mnt/nas_sftp
                
              
    
            
    3. 
          

        


        
        

          
Synchronisation Automatique & Sauvegardes rsync

    2. 
            
  2. L'argument -z compresse les données à la volée pour accélérer les transferts sur connexion WiFi ou distante.
